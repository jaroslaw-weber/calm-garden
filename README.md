# 🌿 Calm Garden

A peaceful box breathing app that helps you relax while growing your own virtual garden. Practice mindfulness, earn coins, and create your perfect garden space.

![Calm Garden Screenshot](https://via.placeholder.com/800x400/4ade80/ffffff?text=Calm+Garden+Screenshot)

## ✨ Features

- 🫁 **Guided Box Breathing** - Visual breathing guide with 4-4-4-4 pattern
- ⭐ **Earn While You Breathe** - Collect 1 coin per second of practice
- 🌸 **Build Your Garden** - Use coins to buy and upgrade plants
- 🔗 **Share Your Garden** - Create and share your garden with friends
- 🎯 **Anti-Cheat System** - Keeps you honest with periodic check-ins
- 📱 **Works Offline** - Your progress is saved locally

## 🚀 Quick Start

### Live Demo
Visit the live app: **[https://jaroslaw-weber.github.io/calm-garden/](https://jaroslaw-weber.github.io/calm-garden/)**

### Local Development

```bash
# Clone the repository
git clone https://github.com/jaroslaw-weber/calm-garden.git
cd calm-garden

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:4321/calm-garden
```

### Building for Production

```bash
npm run build
```

The static files will be generated in the `dist/` folder.

## 🎮 How to Use

1. **Start Breathing** - Click "Start Breathing Exercise" and follow the circle
2. **Watch the Water** - The circle fills as you inhale, empties as you exhale
3. **Earn Coins** - Get 1 coin per second of practice
4. **Build Your Garden** - Go to the Garden tab and spend coins on plants
5. **Stay Present** - We'll check in every minute to make sure you're practicing

### Plant Costs

| Plant | Cost | Emoji |
|-------|------|-------|
| Grass | 1 coin | 🌱 |
| Bush | 2 coins | 🌿 |

*Upgrade plants for 2 coins each level (max level 3)*
